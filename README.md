# 🩺 Raghul's Health Insights

AI-powered app to analyze blood reports and provide detailed health insights, built by Raghul T from Tiruppur, India.

## 🌟 Features

- Agent-based report analysis with AI assistance
- PDF upload support for medical reports
- Secure sign-in and session-based workflows
- Follow-up chat for deeper understanding of results

## 🛠️ Tech Stack

- Streamlit for the UI
- Python for the application logic
- Supabase for authentication and data storage
- Groq and LangChain for AI workflows
- PDF processing for report extraction

## 🚀 Installation

1. Clone the repository
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Configure your environment variables in `.streamlit/secrets.toml`
4. Run the app:

```bash
streamlit run src\main.py
```

## 📁 Project Structure

- `src/` contains the main application code
- `public/db/` contains the database schema script
- `requirements.txt` lists the Python dependencies
